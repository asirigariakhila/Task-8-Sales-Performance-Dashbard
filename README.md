# Task 8: Simple Sales Dashboard Design

## 📌 Project Overview

This project is part of the Data Analyst Internship Task 8.
The objective is to create a simple interactive sales dashboard to analyze sales performance by product, region, category, and month.

## 🛠️ Tools Used

* Power BI
* CSV Dataset
* Optional: Python + Pandas for data cleaning

## 📊 Dashboard Features

* Monthly Sales Trend
* Sales by Region
* Sales by Category
* Total Sales KPI
* Region/Category Filters
* Interactive visualizations

## 📂 Dataset

The dashboard is created using a sales dataset containing fields such as:

* Order Date
* Region
* Category
* Sales
* Profit

## 💡 Key Insights

1. The dashboard shows monthly sales trends and helps identify high-performing months.
2. Sales performance can be compared across different regions.
3. Category-wise analysis helps identify the best-performing product categories.
4. Filters allow users to explore sales data interactively.

## 📁 Deliverables

* Power BI Dashboard
* Dashboard Screenshot/PDF
* Sales Insights Text File

## 🎯 Outcome

This project demonstrates the ability to build a clean and interactive dashboard and summarize sales data visually for business users.
